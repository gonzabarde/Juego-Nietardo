# Jenga de Cultura General

Proyecto escolar — Jenga + cultura general + impresión 3D.

## Contenido

- `Jenga_Cultura_General_Reglas.pdf` — reglas del juego
- `preguntas/SISTEMA_PUNTOS.pdf` — sistema de puntajes
- `datos/Materias_y_Bloques.pdf` — materias, colores y bloques
- `informe/INFORME.pdf` — informe del trabajo
- `3d/Jenga de Cultura General.stl` — bloques para imprimir
- `preguntas/<materia>/nivel-<1|2|3>/cartas.pdf` — cartas de preguntas

## Materias

Historia, Geografía, Ciencias Naturales, Lengua y Literatura, Educación Cívica.

## Jugadores

De 2 a 4.
